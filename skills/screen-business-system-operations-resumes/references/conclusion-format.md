# 招聘者结论卡格式

默认先输出结论卡，再输出证据矩阵。结论只展示事实、缺口、人工下一步和 3–6 个面试问题；分数仅供内部校准，外部名单和飞书候选人记录不展示分数。

## 单份简历

```text
### 初筛结论｜<姓名或姓名未提供>（<candidate_id>）

| 项目 | 结论 |
|---|---|
| 岗位与规则 | 业务系统运维工程师；<JD/Rubric 版本；草稿或已批准> |
| 建议 | 建议二次复核 |
| 核心判断 | <最相关的业务支持、排障、闭环和不确定性> |
| 人工复核 | 一审待完成；二审待完成；原因码：<...> |

最强匹配
- <维度>：<原文、个人动作、位置>

关键缺口 / 待确认
- <简历未提供证据或待核实事实>

下一步
- <一个最重要的人工核验动作>

面试优先验证
1. <问题>
```

结尾固定注明：`以上为非最终简历初筛建议，须由招聘责任人确认。`
