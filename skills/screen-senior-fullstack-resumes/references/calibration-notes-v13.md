# 高级全栈 v13 校准记录

- 生效日期：2026-09-11
- 当前 JD：`senior-fullstack-2026-08-14-v1`
- 当前 rubric：`senior-fullstack-2026-09-11-v13`
- 上一只读版本：`senior-fullstack-2026-09-11-v12`

## 变更原因

招聘口径进一步明确：3–7 年是重要的经验匹配区间，应提高评分比重，但不能作为一票否决项。本科及以上仍是硬门槛；明确语言选择犹豫/抵触和明确外包/驻场开发经历仍是排除项。

## 新判定

- `SEN-EXP-01` 的评分权重由 10% 提高到 20%。
- 3–7 年且证据充分时记为 `preferred_3_to_7_years`；范围外记为 `outside_preferred_range`，年限不清记为 `not_evidenced` 或 `unclear`。
- 年限范围外、年限未写或年限归类不清只影响证据分、优先级和追问，不能单独生成暂不推进或二审。
- `qualification_dimensions` 只保留 `education`。学历不满足生成暂不推进，学历事实冲突或低置信度进入二审。
- 明确语言犹豫/抵触或明确外包/驻场经历仍生成暂不推进；独立/核心项目、AI 和物流经验继续作为优先或加分信号。

## 兼容

v12 及更早记录保持只读，不原地改写。新登记任务使用 v13；历史候选人需要按新口径重新筛选时创建新的版本化任务。
