## 预期结果

候选人能够使用 Go 或 Node.js 承担 BFF/微服务交付，独立完成 Vue3/TypeScript 前端模块，并与算法工程师协作把 LLM、向量检索或 RAG 接入可靠业务链路。高级程度来自复杂约束、架构取舍、重构/性能和生产影响，而非头衔或年限本身。

## 正式 JD

### 核心要求

- 本科及以上、计算机相关专业，3 年以上开发且至少 1 年真实全栈职责。
- Go（Gin/go-zero）或 Node.js（NestJS/Express）生产项目经验。
- 微服务或 BFF 设计与开发经验。
- Vue3、TypeScript、Vite，中后台独立交付和组件化意识。
- MySQL/PostgreSQL、Redis、消息队列，以及数据模型和接口设计能力。
- 理解 LLM API、向量数据库和 RAG，能够与算法工程师协作落地。

### 高级强信号

- 系统重构、计算密集型场景优化、扩展性或稳定性建设。
- 明确的业务/技术约束、方案比较、取舍、生产结果和个人影响。
- 从需求、设计、前后端实现到上线运行的端到端责任。

### 加分项

- 物流或供应链经验。
- 服务发现、熔断、限流等治理经验。
- Kubernetes 或 Docker Compose。
- 同时具备 Go 和 Node.js，或使用 Node.js 集成 AI。
- 与岗位相关的技术博客或开源贡献。
