## 预期结果

候选人具备至少一种后端语言的实际使用基础，能够在项目中完成并解释接口或数据持久化实现，同时理解前端基本概念，并愿意学习 LLM API、向量检索和 RAG。筛选时后端实现深度略高于前端展示广度；重点仍是可培养性和完整做事能力，不是生产规模或高级架构经验。

## 正式 JD

### 行政条件

- 本科及以上在读、计算机相关专业；大三、大四或研二优先。
- 每周至少 4 天实习。

行政信息未写时由人确认；不通过年龄、学校或毕业年份推断。相关专业的等价性由人判断。

### 核心基础

- Go、Node.js、Java、Python 中至少一种后端语言。
- HTTP 和 REST 基本概念。
- HTML、CSS、JavaScript 基础；Vue3 或 TypeScript 为优先项。
- MySQL/PostgreSQL、Redis 和基础 SQL。
- 了解或愿意学习 LLM API、向量数据库和 RAG。

### 职责强信号

- 课程、个人、校内、社团、开源、竞赛或实习项目中的个人实现。
- 单元测试、接口联调、环境部署、文档、Git、Linux 或 Docker 实践。
- 能说明问题、调试过程、反馈迭代和完成结果。

### 加分项

- 物流、供应链或电商项目背景。
- 候选人主动提供的技术博客或 GitHub 项目。
- 算法竞赛、黑客松或编程比赛中的实际工程产出。

## 解释边界

- “大三、大四或研二”是优先项，不是自动淘汰其他在读阶段的规则。
- “计算机相关专业”的等价范围没有完全定义，边界案例由人确认。
- 既有 AI 项目不是简历硬门槛；明确学习行动或可验证动机也可作为信号。
