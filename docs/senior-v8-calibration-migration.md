# 资深全栈 v8 校准迁移

## 变更目的

v8 保留 v7 的 Go 硬门槛、事实清单、独立评分与复核状态，同时修正同岗位人工样本暴露的两个漏筛点：把独立前端当作直接推进必备项，以及把只有完整 `E3` 的候选人才视为达到高级门槛。

## 决策变化

- Go 后端项目 `E2` 仍为不可替代的硬门槛。
- `SEN-FE-01` 从推进门槛改为画像区分与面试验证项。
- `SEN-LEVEL-01` 推进最低值从 `E3` 调整为 `E2`；`E3` 的五项事实清单不变，继续作为高确定性优先信号。
- `SEN-EXP-01` 明确包含应用研发方向；运维/平台方向模糊时使用 `U09/U04`，不按技术词数量直接判定。
- 负面核心集合不再包含前端，改为 Go、架构、数据和个人责任/高级程度。
- 人工原因按能力、硬资格、流程/商业、意向和未知分层；后三类不校准能力分。

## 兼容策略

- 新任务写入 `schema_version: 1.2`、`rubric_version: senior-fullstack-2026-09-01-v8`。
- v2–v7 历史记录继续只读校验，不原地改变建议或 scorecard。
- v7 中因前端不足或未达到 `E3` 被送二审/暂不推进的记录属于受影响集合，应从原始简历按 v8 重筛。
- 评分权重和 `evidence-score-2026-09-01-v2` 暂不调整；当前样本不足以支持精确调权。分数只表示证据覆盖，不覆盖 Go 门槛和人工流程。
