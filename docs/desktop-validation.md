# 桌面预览版验收记录

2026-09-08，ResumeDesk 0.2.0-preview。当前交付 Windows 免安装包及跨平台构建源码；不能视为全部规格正式验收完成。

## 已交付功能

- 中文桌面：本地导入、文件名前缀岗位分流、目录监听及停止接收。
- 无 API 整理：PDF/扫描 PDF/DOCX/TXT/MD、本地 OCR、来源副本、内容去重、解析错误状态、文本搜索与岗位规则原文。
- 人工审阅：逐项结论与证据/备注、信息不足、未审阅状态、自填审阅者、自动保存草稿、历史修订和 CSV/Markdown 导出。
- 可选模型：MiniMax 原协议及 OpenAI 兼容协议、HTTPS 地址校验、拒绝重定向、系统凭据存储、合成连接测试、逐份显式付费调用、独立运行历史、结果预览与导出。
- 每次 AI 运行使用独立队列与配置快照，支持多选批量分析并在同端点/模型已有历史运行时提示重复计费；错误响应不自动付费修复，认证失败或限流会暂停当前批次，超时不盲目重发，人工结果不被覆盖。
- 设置页支持带版本清单的数据 ZIP 备份与恢复，恢复前自动生成回滚备份，替换失败会自动恢复原数据；若回滚本身也遇到文件系统错误，会提示使用回滚备份。API Key、模型配置和飞书凭据不会写入备份。
- 飞书可选：用户自己的资源和字段配置、外部 CLI 路径、dry-run 预检查与单轮文档同步；本地功能不依赖飞书。

## 与完整规格的差异及发布条件

1. Windows 交付免安装 ZIP：解压后双击 exe。没有安装向导、桌面快捷方式注册或“添加/删除程序”条目；删除程序目录即可移除便携版，用户数据和系统凭据保留。
2. Mac 当前只有源码和原生构建入口，没有已生成或已验收的 .app。两类 Mac 目标均为 macOS 14+；旧 Air 若不支持该系统，需要独立兼容工作。需分别在对应架构机器上运行 scripts/build-macos.command 或使用说明中的构建命令。
3. 发行包未签名；Mac Developer ID、公证和 Windows 发布签名尚未进行。
4. 未用真实收费 API 或真实简历进行模型调用。协议、错误和现有三岗位输出合同通过合成测试，真实供应商质量/费用行为仍需使用者小样校准。
5. 飞书尚未真实联网验证。依赖安装与登录由用户/管理员完成；桌面仅提供预检查和单轮文档同步，未接入桌面 AI 结果回写、人工意见回写或长期飞书监听。既有 CLI 功能继续保留。
6. 自动重试退避、安装升级器和自定义岗位不是本预览版的已验收功能；桌面批量分析目前按选择顺序逐份明确发起，认证失败或限流会停止后续消费，修正配置或等待服务恢复后需显式重新发起，不提供并发或自动重试。

后续顺序：获取 Mac 构建机并完成两架构离线 smoke → 真实模型及飞书测试空间小样验证 → 补齐安装发布及未完成的规格项目 → 签名后正式交付。

## 数据与兼容性

没有读取或修改开发项目 .env、既有简历和运行数据库；没有执行真实飞书写入。保留原有 output docs/ 与 tmp/ 未跟踪内容。没有提交、推送、创建分支或发布项目。

桌面人工库 schema v1，拒绝打开更高版本；不迁移原 CLI 库。新增 keyring 25.6.0 与构建组 PyInstaller 6.22.0，Intel Mac 另用 ONNX Runtime 1.23.2。可回退到原 CLI，桌面数据独立保留。

发行包包含第三方许可材料；其中既有 PyMuPDF 的 AGPL/商业许可边界在正式对外分发前需结合项目分发方式处理。当前没有购买许可证或上传代码/材料至外部服务。
